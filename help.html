🔖 书签管家 · 功能说明

书签有效性检测 · 搜索 · 分组 · 排序 · 批量导入导出

一、工具栏弹窗（点击浏览器工具栏图标）

1. 搜索与范围选择

  • 搜索框支持实时过滤，输入即出结果。
  • 搜索框下方的三个胶囊按钮（标题 / 网址 / 分组）可以点击：勾选或取消，决定搜索匹配的范围——标题匹配书签名、网址匹配 URL、分组匹配文件夹名（命中分组时该分组下全部书签整组显示）。
  • 结果按文件夹分组展示，分组头显示数量，默认折叠，点击分组头展开/收起；搜索时自动全部展开。

2. 收藏当前页

  • 点击收藏当前页，面板中会预填当前页签的标题，可在收藏前修改标题。
  • 在「搜索分组」框中按分组名筛选目标分组（列表显示完整层级路径），点击分组即完成收藏。

3. 导入 / 导出

  • 导入：选择 Netscape 标准书签 HTML 文件，批量导入到按日期命名的新分组，不污染既有书签。
  • 导出：一键导出当前全部书签（标准 Netscape 格式，可与其他浏览器互导）。选择性导出请在管理页使用。

4. 检测有效性

  • 对全部 http(s) 书签发起网络可达性探测，完成后不可达的书签标记红色徽标。
  • 更精细的检测与重检请使用管理页。

二、管理页（弹窗 → 打开管理页）

1. 分组与排序

  • 勾选按文件夹分组时按书签栏实际目录折叠展示，每组标题显示可见书签数量，组内可「打开全部」。
  • 排序方式：添加时间（新→旧 / 旧→新）、网址 A→Z、标题 A→Z。

2. 有效性检测与不可达清单

  • 点击检测有效性对全部书签检测，结果实时显示（可达 / 不可达 / 检测中）。
  • 不可达清单中每项有勾选框，支持「全选」；点击重新检测时——勾选了若干项则只重检勾选项，一个不勾则重检全部不可达。
  • 清单中每项可单独「打开」验证或「删除」清理。

3. 选择性导出（指定分组 / 指定书签）

  • 点击导出弹出导出面板，两种模式：
    • 全部书签：一键导出全部。
    • 自定义选择：在目录树中勾选——勾选分组导出该分组整棵子树；只勾选分组内的部分书签则仅导出勾选的书签（保留其所在层级）。可任意组合。
  • 导出为 Netscape 标准格式 HTML，可直接导入 Chrome 原生书签管理器或其他浏览器。

4. 编辑与删除

  • 每条书签支持「打开 / 编辑（标题与网址）/ 删除」。

三、检测原理与局限（重要）

扩展采用三重探测以降低误报，任一成功即判定可达：

顺序策略说明
1no-cors GET标准 fetch 探测，10 秒超时
2favicon 图片探测用图片加载器加载站点 favicon，绕过 fetch 栈限制
3GET 重试排除瞬时网络抖动
受浏览器安全策略（CORS）限制，检测只能判断「网络层是否可达」（DNS 失败、超时、离线），无法准确识别 HTTP 404/500；无 favicon 且严格拦截探测的站点仍可能被误判为不可达。检测结果应作为「疑似失效」参考。

四、常见问题

Q：检测前弹出的提示是什么？

是网络环境提醒：请在稳定网络下检测，且明确告知检测的局限（见上节）。

Q：导入的书签去了哪里？

整体落在书签栏下「导入书签-日期时间」新分组中，确认无误后可自行整理或删除该分组。

Q：首次打开弹窗时的黄色提示？

首次使用引导，提醒范围胶囊可点击。点击「知道了」或任意胶囊后不再显示。
