🔖 书签管家 · 功能说明

书签有效性检测 · 搜索 · 分组 · 排序 · 批量导入导出

一、工具栏弹窗（点击浏览器工具栏图标）

1. 搜索与范围选择

  • 搜索框支持实时过滤，输入即出结果。
  • 搜索框下方的三个胶囊按钮（标题 / 网址 / 分组）可以点击：勾选或取消，决定搜索匹配的范围——标题匹配书签名、网址匹配 URL、分组匹配文件夹名（命中分组时该分组下全部书签整组显示）。
  • 结果按文件夹分组展示，分组头显示数量，默认折叠，点击分组头展开/收起；搜索时自动全部展开。

2. 收藏当前页

  • 点击收藏当前页，面板中会预填当前页签的标题，可在收藏前修改标题。
  • 在「搜索分组」框中按分组名筛选目标分组（列表显示完整层级路径），点击分组即完成收藏。

3. 导入 / 导出

  • 导入：选择 Netscape 标准书签 HTML 文件，批量导入到按日期命名的新分组，不污染既有书签。
  • 导出：弹出导出面板，可选「全部书签」或「自定义选择」（勾选分组 / 分组内指定书签）。目录树默认折叠，点击分组展开后可只勾选组内部分书签，避免书签过多时难以定位。

4. 检测有效性

  • 对全部 http(s) 书签做「本地 + 在线」双重可达性探测，结果分三类标记：可达、网站故障（全球均不可达）、本地访问不可达（仅本地网络打不开、全球正常）。
  • 更精细的检测与重检请使用管理页。

二、管理页（弹窗 → 打开管理页）

1. 搜索、分组与排序

  • 顶部搜索框右侧提供标题网址分组三个范围胶囊，可以点击勾选/取消，决定搜索匹配的范围（与弹窗一致；命中「分组」时该分组下书签整组显示）。
  • 勾选按文件夹分组时按书签栏实际目录折叠展示，每组标题显示可见书签数量，组内可「打开全部」。
  • 排序方式：添加时间（新→旧 / 旧→新）、网址 A→Z、标题 A→Z。

2. 有效性检测与不可达清单

  • 点击检测有效性对全部书签检测，结果实时显示（可达 / 网站故障 / 本地访问不可达 / 检测中）。
  • 每条书签右侧的检测按钮可只对这一个网址做检测，结果实时刷新，并同步进不可达清单（检测为可达时会自动从清单移除）。
  • 不可达清单中每项有勾选框，支持「全选」；点击重新检测时——勾选了若干项则只重检勾选项，一个不勾则重检全部不可达。
  • 清单中每项可单独「打开」验证或「删除」清理。

3. 选择性导出（指定分组 / 指定书签）

  • 点击导出弹出导出面板，两种模式：
    • 全部书签：一键导出全部。
    • 自定义选择：在目录树中勾选——勾选分组导出该分组整棵子树；只勾选分组内的部分书签则仅导出勾选的书签（保留其所在层级）。可任意组合。
  • 目录树默认折叠（避免书签过多）：直接勾选分组即导出整组；点击分组名展开后，可只勾选组内需要的书签。
  • 导出为 Netscape 标准格式 HTML，可直接导入 Chrome 原生书签管理器或其他浏览器。

4. 编辑、勾选与删除

  • 每条书签左侧有勾选框：勾选任意条目后顶部出现选择栏「已勾选 N 个书签」，可删除勾选（自定义批量删除）或取消选择。
  • 每条书签右侧支持「检测 / 打开 / 编辑（标题与网址）/ 删除」。
  • 每个分组标题右侧删除分组可连同其下全部书签与子分组一并删除（需二次确认；书签栏、其他书签这两个顶层节点不可删除）。

三、检测原理与局限（重要）

扩展采用「本地 + 在线」混合探测，本地能打开即判定可达；本地打不开时再改用在线多节点检测，规避本地网络偶发异常导致的误判。

阶段策略说明
本地三重探测no-cors GET → favicon 图片探测 → GET 重试（10 秒超时）。本地能打开即判定「可达」。
在线check-host.net 多节点 TCP本地不可达时，由后台 Service Worker 调用 check-host.net，从多个地理节点（默认 3 个）同时建立 TCP 连接，得出「全球可达性」结论。Service Worker 的 fetch 不受扩展页 CORS 限制。

结果标记三类：

标记含义处理建议
可达本地或在线任一节点能连接正常，无需处理
网站故障在线多节点全部连接失败（全球不可达）站点确实挂了，建议删除或修复
本地访问不可达本地失败、但在线多节点能连接（仅本地网络/防火墙/地区限制）；或在线服务偶发不可用时保守标记站点本身正常，多是你本地打不开，可保留
本地探测受浏览器安全策略（CORS）限制，只能判断网络层是否可达（DNS 失败、超时、离线），无法准确识别 HTTP 404/500；无 favicon 且严格拦截探测的站点本地探测可能失败，但会由在线检测再判定。在线检测依赖第三方免费服务，可能稍慢且存在限流（扩展已做最小请求间隔与重试缓解）。检测结果应作为「疑似失效」参考。

四、常见问题

Q：检测前弹出的提示是什么？

是网络环境提醒：请在稳定网络下检测，且明确告知检测的局限（见上节）。

Q：导入的书签去了哪里？

整体落在书签栏下「导入书签-日期时间」新分组中，确认无误后可自行整理或删除该分组。

Q：首次打开弹窗时的黄色提示？

首次使用引导，提醒范围胶囊可点击。点击「知道了」或任意胶囊后不再显示。
